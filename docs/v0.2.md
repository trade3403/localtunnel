# V0.2 域名网关候选版

## 已实现代码（等待新 CI）
- 1–64 个显式域名到本机 relay 端口的静态映射；拒绝重复域名、通配符、无效端口、配置注入。
- Rust CLI 生成独立 Nginx HTTP/HTTPS 网关配置；不会修改现有 Nginx 站点或自动重载生产服务。
- TLS 1.2/1.3，使用管理员提供的 SAN 证书及私钥；拒绝未知 SNI、未知 Host 和 SNI/Host 不一致。
- HTTP/1.1、WebSocket upgrade、固定上游、代理转发头重写、基本请求体和超时限制。
- Linux 真实 Nginx + Rathole E2E，Windows Rust 单测及原有隧道回归；本地临时域名和独立信任测试证书，不使用生产 DNS。

## 使用示例（Linux 测试环境）
    localtunnel gateway-http /tmp/lt-http.conf 127.0.0.1:18080 web.example.test 20800 api.example.test 20801
    localtunnel gateway-https /tmp/lt-https.conf 127.0.0.1:18443 /tmp/cert.pem /tmp/cert.key web.example.test 20800 api.example.test 20801

先确保前置 relay 已启动且映射端口匹配；使用空的专用 Nginx prefix、绝对配置文件路径，执行 nginx -p <prefix>/ -c <config> -t 后才启动。测试时可使用 curl --resolve 指定回环地址；HTTPS 使用受信任测试证书，不关闭证书校验。证书文件不得提交 Git。当前采用同一 SAN 证书覆盖本次配置所有域名。
