## 已验收与边界

管理请求及连接限流、认证配额、设备吊销、回环访问边界、Linux私有数据库保护、受控日志保留及容量保护、SQLite一致性备份与隔离恢复、真实负载、120秒连接寿命、真实 Noise HTTP/HTTPS 传输和短时常驻均通过开发预览回归。旧 V0.4 功能与 Windows 回归保留。具体限制及运行入口见 [V0.5](v0.5.md) 和 [V0.4 验收](v0.4-acceptance.md)。

尚未完成：生产远程TLS控制面/跨主机公网E2E、ACME、真实域名与设备、长期168小时老化、全盘硬配额、分布式限流和公平性、生产备份/密钥轮换、完整依赖安全及许可审计、签名升级和正式发布。当前5分钟测试不是最终生产安全验收。不得用本阶段结果覆盖这些未完成门禁。

## V0.6 下一阶段

按 [路线](architecture-and-roadmap.md) 推进 Linux/macOS/ARM64 agent。先做原生目标矩阵及可信引擎来源/摘要核验，再做每平台实际加密回环、私有配置和可控进程生命周期、受保护凭据、服务管理及打包。每平台分别声明支持范围；不把交叉编译当原生实测，不把本机测试当公网。仅用标准免费 hosted runner，不因目标不支持而假报测试；缺少可验证引擎或 runner 时记录阻塞。跨主机公开验收依旧需要用户授权的设备/入口。验收文档提交后继续复核 CI，再从该已核验基线创建 V0.6 开发分支。
