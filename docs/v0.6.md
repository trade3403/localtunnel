## 第一增量：原生构建、私有配置及引擎候选证据

公开仓库仅使用 GitHub 标准免费 hosted runner，非 larger runner。原生四平台矩阵：

| Runner | 原生 CLI | Rathole v0.5.0 上游候选 |
|---|---|---|
| ubuntu-24.04 | Linux x64 | x86_64-unknown-linux-gnu |
| ubuntu-24.04-arm | Linux ARM64 | aarch64-unknown-linux-musl |
| macos-15-intel | macOS Intel | x86_64-apple-darwin |
| macos-15 | macOS Apple Silicon | 无原生发行归档，待可信源码构建 |

标签依据：https://docs.github.com/en/actions/reference/runners/github-hosted-runners 。引擎候选依据：https://api.github.com/repos/rathole-org/rathole/releases/tags/v0.5.0 。三份上游资产没有提供 digest 字段，当前只观察归档与二进制 SHA256、大小及 ELF/Mach-O 架构，不执行、不解压至磁盘、不把观测摘要称为独立官方签名。Apple Silicon 明确输出 blocked，CLI 测试仍强制执行，不把 Rosetta 当原生引擎。后续核对候选来源和重复下载、提交可信锁定记录，再实际原生加密 E2E。Apple Silicon 单独审查固定源码提交、锁定依赖及原生构建；不能在本轮标记隧道通过。

四平台均真实 cargo test/build --locked，核验编译器 host、系统架构及实际 ELF/Mach-O 指令架构，执行 CLI --version；真实配置生成验证 0600、拒绝覆盖及符号链接目标、拒绝非回环目标和非法映射名、秘密不输出。产物为未签名 CLI 和 SHA256，以及各自 JSON 证据。仍保留全部原 Windows、Gateway、管理测试；管理 push 增加 V0.6 分支。无新产品依赖。
