## 桌面端候选功能
- Tauri 2 + Vue 3 工作台；可配置中转地址、服务端 Noise 公钥、经过校验的 Rathole EXE 绝对路径，添加/删除 1–64 个本地映射。
- 每映射独立 token，UI 密码字段遮挡；Rust 复用原核心验证名称、端口、token、公钥及重复映射规则。本地地址固定 127.0.0.1。
- 真实 Tauri IPC 启动和停止 Rathole 子进程。临时配置仅在进程生命周期内存在，正常停止/通过托盘退出会清理；不写持久凭据。进程运行不等于已连接，不虚构公网在线状态。引擎日志暂不展示，避免泄露凭据。
- 需要管理员提前在中转服务端配置同名映射、授权 token、域名。界面暂不直接分配域名或修改服务端。
- 开发预览默认不随系统启动；关闭主窗口后隐藏到系统托盘，当前登录会话内继续运行，不是 Windows Service。强制结束进程或系统异常后的子进程/临时文件清理仍需专项测试。Windows 临时目录依赖当前用户 ACL；生产版本需凭据保护和 Windows Job Object/Service。

## Windows 本地开发
安装 Rust stable MSVC、Visual Studio C++ build tools、Node.js、WebView2 及 Python。进入仓库根目录：
    
    python apps/desktop/scripts/create_icons.py
    cd apps/desktop
    npm install
    npm run tauri -- dev

构建预览安装包：npm run tauri -- build --bundles nsis 。Rathole v0.5.0 需从官方来源获取并校验；本预览不随安装包内置引擎，操作员填写可信 EXE 路径。依赖锁文件由首次 CI 产生并留档，后续审查并提交 lockfile 才视为可复现构建。

## 系统托盘与非秘密配置增量（待 CI）

- Tauri 原生托盘菜单：显示主窗口、停止隧道、退出 LocalTunnel。关闭主窗口隐藏到托盘，退出前停止受管子进程。只支持当前登录会话内常驻，不声称已实现 Windows Service、注销后运行或开机自启。
- 保存/读取配置需要明确点击，运行时禁止编辑；保存到当前用户 app_config_dir/profile.json。原子替换 JSON，大小限制 128 KiB，Rust 核心校验节点地址、端口、映射名称和公钥。严格拒绝未知字段（包括 token）；仅保存非秘密配置，读取后必须重新输入各映射 token。不会自动启动隧道。公钥不是私钥。暂未实现 DPAPI/凭据管理器。
- 新增配置文件往返、覆盖、无 token、非法端口、未知字段和超限测试。Windows 桌面工作流继续执行真实隧道进程及 NSIS 安装包构建；托盘真实点击、系统注销和异常终止仍待验收。
