# V0.4 管理服务（首个开发增量）

沿用架构文档的 Axum + SQLx/SQLite 方案，新建独立 crate `crates/server`，不改变现有核心和桌面锁文件。首个增量只提供 Linux 回环管理服务骨架、真实数据库迁移、健康和就绪接口，不启用匿名用户/设备/映射接口、不应用实际隧道或网关配置。

本地开发（Linux，非生产）：

    mkdir -m 700 local-data
    cargo run --manifest-path crates/server/Cargo.toml -- local-data 9000
    curl http://127.0.0.1:9000/healthz
    curl http://127.0.0.1:9000/readyz

数据目录应由可信运行账户独占并保护其父目录；不接受组或其他用户可访问的目录及数据库符号链接。当前不是完整文件系统安全审计。初始迁移包含 users、devices、nodes、domains、mappings；独立凭据摘要、密码哈希字段、归属复合外键、域名和节点端口唯一约束、映射默认禁用。没有初始管理员或默认密码；没有登录、设备注册、域名验证、状态上报及配置应用，不能用于正式管理。

首轮 CI #1/#2 已通过，锁文件从两份独立 CI 日志逐字比较一致后提交。后续 CI 使用 cargo test/build --locked 并检查锁文件无变化；严格锁定复验尚待通过，之后进入管理员认证。测试覆盖实际 Axum 监听、数据库迁移/重启、约束拒绝、就绪失败与不安全目录；无公网、无生产数据。

## 管理员认证增量（待 CI）
可信本地账户执行 `localtunnel-server --init-admin <private-data-directory>`，从受保护 stdin 输入 username/password JSON，密码12–256 UTF-8 字节；不放入命令参数、历史或日志。仅空 users 表允许初始化，无默认密码。Argon2id 19MiB/t2/p1随机盐；32字节 OS 随机 Bearer Token 仅存 SHA256 摘要，一小时有效、单管理员会话；登录轮换、注销、禁用、降权和密码变更撤销会话。POST /api/v1/auth/login、GET /api/v1/auth/me、POST /api/v1/auth/logout；仅管理员。成功响应 no-store，4KiB 请求体上限，每进程全局12次/60秒登录预算、最多2个哈希工作者，重启重置且共享预算可能阻塞。仍为回环预览；生产 HTTPS、MFA、密码修改恢复、普通用户登录与设备配对未实现。新依赖一次性解析 lock，回收后恢复严格锁定复验。
