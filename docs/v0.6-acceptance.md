## 实际证据结果

每平台独立核对27个报告结果组（合计108个平台-结果组，不等同于108个独立底层断言）：原生CLI/配置3，私有store4，真实隧道7，前台进程4，用户服务5，安装包4。各组均通过。

- 真实隧道：Rust 配置生成、错误 token 不能转发、真实 HTTP 正文穿透、重复请求、relay 重启后 agent 重连、两个映射隔离、32个并发交错请求。
- 私有store：实际文件权限/所有者/输入检查、拒绝危险路径/链接/覆盖、无凭据输出。
- 进程：固定引擎摘要安装、拒绝篡改、真实前台 exec 和锁、TERM/KILL 后释放与恢复。
- 服务：定义及拒绝覆盖、拒绝CLI硬链接、真实启动及正文、SIGKILL后新PID重新转发、停止/disable或bootout。Linux systemd user 两平台，macOS GUI launchd 两平台。
- 安装包：坏归档摘要/路径穿越拒绝、坏成员摘要拒绝、私有安装及不覆盖、**从真实安装包安装的CLI和引擎完成前台与系统服务测试**。六成员是两个二进制、manifest、README、上游LICENSE和NOTICE；install.py在外层ZIP中。没有配置、凭据或用户数据。
- Apple Silicon 上游没有预编译发行包：实际由固定 commit ebb764ae53d7ffe4fcb45f83f7563bec5c74199d / Cargo.lock blob 6856445f5a0a006fa2d425c97214219e5202541d / Rust 1.79.0 ARM64 / server,client,noise 构建，测量本次二进制哈希并嵌入配套CLI，不是上游签名或跨构建可复现承诺。
